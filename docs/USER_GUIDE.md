# Guía de Usuario

## Inicio de sesión
1. Ejecutar `python main.py`
2. Ingresar usuario y contraseña
3. Al iniciar, se abre dashboard según rol

## Flujos principales
- Pacientes: registro, edición, búsqueda avanzada y eliminación lógica
- Citas: programación y vista de calendario
- Reportes: PDF y Excel
- Auditoría: visible solo para rol **Admin**
